# Jump Gap — Telegram Mini App

Небольшой бесконечный платформер: удерживай кнопку, чтобы зарядить прыжок, и отпускай, чтобы прыгнуть. Чем дольше удержание, тем дальше прыжок.

## Файлы

- `index.html` — игровая разметка
- `style.css` — оформление
- `game.js` — логика игры
- `bot.py` — Telegram-бот на aiogram 3
- `requirements.txt` — зависимости Python

## 1. Проверить игру в браузере

Открой `index.html` в браузере. Для проверки самой игры Python и Telegram-бот не нужны.

## 2. Настроить Python в PyCharm

1. Открой папку проекта в PyCharm.
2. Создай виртуальное окружение, если PyCharm не сделал это автоматически.
3. Открой Terminal в PyCharm и выполни:

   ```bash
   python -m pip install -r requirements.txt
   ```

## 3. Опубликовать веб-игру

Telegram требует HTTPS-адрес для Mini App. Можно использовать GitHub Pages:

1. Создай репозиторий на GitHub.
2. Загрузи `index.html`, `style.css` и `game.js` в корень репозитория.
3. Открой Settings → Pages.
4. Выбери публикацию из ветки `main` и папки `/ (root)`.
5. После публикации скопируй адрес сайта вида `https://username.github.io/repository/`.

Ссылка может появиться не сразу. Проверь, что сайт открывается по HTTPS.

## 4. Создать Telegram-бота

1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot` и следуй инструкциям.
3. Сохрани токен в секрете. Не вставляй токен в код и не публикуй его на GitHub.
4. Задай две переменные окружения перед запуском бота:
   - `BOT_TOKEN` — токен от BotFather
   - `WEBAPP_URL` — HTTPS-адрес опубликованной игры

### Windows PowerShell

В терминале PyCharm:

```powershell
$env:BOT_TOKEN="ВСТАВЬ_СВОЙ_ТОКЕН"
$env:WEBAPP_URL="https://username.github.io/repository/"
python bot.py
```

Эти команды задают переменные только для текущего окна терминала. При новом запуске их нужно задать снова.

## 5. Проверить в Telegram

1. Запусти `bot.py` в PyCharm.
2. Открой своего бота в Telegram и отправь `/start`.
3. Нажми кнопку «Играть в Jump Gap».

Бот должен работать, пока запущен скрипт `bot.py`. Для постоянной работы его позже нужно разместить на сервере.

## Управление

- Телефон: зажми и держи зелёную кнопку, затем отпусти.
- Компьютер: удерживай `Space` или `↑`, затем отпусти.
- После проигрыша нажми «Играть снова».

## Перед публикацией на GitHub

Не добавляй в репозиторий токен бота, пароли или другие секреты. Игровые HTML/CSS/JS-файлы можно публиковать открыто.
